# HomePage DataPlate

## Visão Geral

`HomePage DataPlate` é um projeto acadêmico que apresenta uma página inicial responsiva com visual moderno e navegação intuitiva. A interface foi construída usando HTML5, CSS3 e JavaScript, com inspiração em referências de design coletadas na internet.

## Funcionalidades

- Layout responsivo para desktop e dispositivos móveis
- Navegação simples e organizada
- Uso de elementos visuais modernos e tipografia amigável
- Estrutura semântica em HTML5
- Estilos personalizados em CSS3
- Comportamento interativo com JavaScript

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## Como Executar

1. Abra a pasta do projeto em seu editor de código preferido.
2. Abra o arquivo `index.html` no navegador.

> Não é necessário instalar dependências adicionais — basta carregar o HTML no navegador.
